POLICY / 2026-08-28

Understand what stays on your device

AWB itself has no telemetry or account code. The CLI source contains no network client.

Policies and receipts

AWB traverses the watched paths named in your policy. The wrapped command may access other readable paths.

Receipts are written to the path you choose. They include local paths, metadata, hashes, the command, and its exit code.

Documentation site

This site loads runtime files only from its own origin. It sets no analytics cookies and uses no trackers.

The service worker caches public pages for offline reading. Demo state uses only keys beginning with demo:awb:.
